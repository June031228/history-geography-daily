## 关键经验沉淀

1. **腾讯文档写入响应歧义**：`mcp__tencent-docs__smartcanvas.edit` 与 `tencentdocs.py tdoc_call` 调用后返回 `{"error":"","trace_id":"..."}` 时，**空字符串 error 字段不代表失败**，实际是成功的标志（异步写入已发生）。要确认是否真的写入了，必须先调 `smartcanvas.find` 查询文档内容。不要基于这个空 error 重试 INSERT_AFTER。

2. **GitHub push 失败模式**：
   - 网络层 443 阻塞：`Recv failure: Connection was reset` / `Failed to connect to github.com:443 after 21000 ms` — 等几秒重试通常可恢复
   - 凭证层：`Invalid username or token. Password authentication is not supported` — git credential helper 缓存问题，需 `git remote set-url` 重置或等 gh CLI 重新注入 token
   - 首次 push 失败时建议先 retry 一次（同网络抖动），失败后再换凭证策略

3. **清理腾讯文档重复段落**：每次清理前用 `smartcanvas.find` 按精确短语搜索，按内容分组保留最早插入的 block ID，其余全部 DELETE。注意某些 Heading（如"上节回顾""明日预告"）跨多课存在，重复计数不能简单当重复处理。
